# Examples

Each file is a worked output written by following the skills for one invented channel or show. The request at the top of each file is what the agent was given. Channels, people, brands, and samples are invented, and every audience number is left as a placeholder so no one mistakes it for a benchmark. These examples were written by hand from the skill instructions, not captured from a live run in an AI tool.

| Example | Skills used |
| --- | --- |
| [Coffee channel: one video, full package](coffee-channel-video-package.md) | `creator-video-script`, `creator-seo-metadata`, `creator-repurpose-posts` |
| [Interview podcast: one episode](interview-podcast-episode.md) | `creator-podcast-episode`, `creator-clip-finder` |
| [Craft channel: a brand pitch](craft-channel-brand-pitch.md) | `creator-brand-pitch`, `creator-sponsor-read`, `creator-posting-calendar` |

Use them to see what good output looks like, and as test cases when you change a skill: follow the changed skill with the same request and compare.
